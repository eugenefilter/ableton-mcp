# Changelog

Все значимые изменения в проекте AI Agent for Ableton Live документируются в этом файле.

## [2.0.0] - 2025-10-01

### 🎉 Добавлено

- **Amen Break Generator** - автоматическое создание классического jungle/dnb паттерна
- **Расширенное API** для создания MIDI клипов и программирования нот
- **Комплексный тестер API** (`test_api.py`) для проверки всех функций
- **Детальная документация** с примерами использования
- **AI-готовая архитектура** для интеграции с LLM

### 🎵 Новые API команды

- `create_midi_clip` - создание MIDI клипов с настройкой длительности и loop
- `set_clip_notes` - программирование нот в существующих клипах
- `add_notes` - добавление нот к существующим
- `launch_clip` - запуск конкретных клипов

### 🛠️ Улучшения

- **Более надежная обработка ошибок** с полным логированием
- **Undo steps** для всех операций изменения проекта
- **Thread safety** для UDP коммуникации
- **Лучшая архитектура** с разделением на компоненты

### 📚 Документация

- **Подробные примеры использования** всех API функций
- **Схема архитектуры** проекта
- **Roadmap** для будущих версий
- **Troubleshooting** секция
- **Участие в разработке** руководство

## [1.0.0] - 2025-09-XX

### 🎉 Первый релиз

- **Базовый Control Surface скрипт** для Ableton Live 11
- **HTTP-UDP мост** для внешнего управления
- **Основные команды**: play, stop, set_tempo, create_midi_track
- **Автоматическая установка** через setup.py
- **Базовая документация** и примеры

### 🏗️ Архитектура

- **MyAgent** Control Surface скрипт
- **bridge.py** HTTP сервер + UDP клиент
- **UDP связь** на портах 8788/8789
- **HTTP API** на порту 8787
