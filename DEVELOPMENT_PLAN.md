## ЭТАП 1: ФУНДАМЕНТ

### Шаг 1.1 — Структура проекта и зависимости
- Создать структуру директорий (src/ableton_mcp/...)
- Инициализировать pyproject.toml (Poetry) или requirements.txt
- Создать .gitignore, .env.example
- **Тест:** `pip install -e .` работает без ошибок

### Шаг 1.2 — Конфигурация и утилиты
- Система конфигурации (Pydantic Settings)
- Структурированный логгер
- Кастомные исключения
- Базовые валидаторы
- **Тест:** импорт модулей работает, конфиг читает .env

## ЭТАП 2: СВЯЗЬ С ABLETON

### Шаг 2.1 — OSC клиент
- Базовый OSC клиент (python-osc)
- Подключение к AbletonOSC
- Отправка и получение сообщений
- Обработка ошибок подключения, reconnect
- **Тест:** ping Ableton, получить/установить tempo

### Шаг 2.2 — Базовые операции с Ableton
- Transport: play, stop, record, tempo
- Track management: создание MIDI/Audio треков
- Clip operations: создание клипов, добавление нот
- Device control: загрузка устройств, параметры
- Mixer: volume, pan, sends
- **Тест:** создать трек, добавить клип с нотами в Ableton

### Шаг 2.3 — Минимальный MCP сервер
- Создать базовый MCP Server
- Обернуть операции в MCP tools (5-10 tools)
- Подключить к Claude Desktop
- **Тест:** через промпт Claude создать трек в Ableton

## ЭТАП 3: ГЕНЕРАЦИЯ МУЗЫКИ

### Шаг 3.1 — Музыкальная теория
- Модуль гамм (scales) — все основные лады
- Модуль аккордов (chords) — построение и прогрессии
- Интервалы, транспозиция
- MIDI утилиты (нота ↔ число, валидация)
- **Тест:** unit-тесты — правильные ноты для каждой гаммы/аккорда

### Шаг 3.2 — Базовые генераторы
- Melody Generator — генерация мелодий на основе гаммы
- Bass Generator — генерация басслайнов
- Rhythm/Drum Generator — генерация ударных паттернов
- Harmony Generator — аккордовые прогрессии
- **Тест:** сгенерировать паттерн, проверить что ноты в гамме

### Шаг 3.3 — Интеграция генераторов с MCP
- MCP tools для генерации (generate_melody, generate_bass, etc.)
- Параметры: key, scale, tempo, bars, style
- Валидация входных данных
- **Тест:** "создай мелодию в A minor" → ноты появляются в Ableton

## ЭТАП 4: СТИЛИ И ЖАНРЫ

### Шаг 4.1 — Плагин-система стилей
- Абстрактный класс StylePlugin
- StyleRegistry для регистрации и выбора стилей
- Интерфейс: default_tempo, preferred_scales, generate_*
- **Тест:** зарегистрировать стиль, получить по имени, вызвать методы

### Шаг 4.2 — Goa Trance стиль
- Темп: 138-145 BPM
- Гаммы: harmonic minor, phrygian dominant
- Lead: быстрые психоделические арпеджио (16th notes)
- Bass: rolling 16th notes
- Drums: 4-on-the-floor kick, offbeat hats
- Структура: длинные билды, атмосферные брейки
- **Тест:** "создай goa trance трек" → характерное звучание жанра

## ЭТАП 5: ПОЛИРОВКА

### Шаг 5.1 — Arrangement (структура трека)
- Секции: intro, buildup, drop, breakdown, outro
- Автоматическое расположение клипов на timeline
- Вариации паттернов между секциями
- Переходы и автоматизация
- **Тест:** полный трек 64+ тактов с переходами между секциями

### Шаг 5.2 — Сведение
- Автоматическая установка громкости треков
- Панорама
- Sends (reverb, delay)
- Базовый баланс микса
- **Тест:** трек звучит сбалансированно, инструменты не конфликтуют

### Шаг 5.3 — Тесты и документация
- Unit + integration тесты, coverage >80%
- README.md с quick start
- API reference (все MCP tools)
- Примеры промптов для пользователей
- **Тест:** все тесты проходят, новый пользователь может запустить по README
