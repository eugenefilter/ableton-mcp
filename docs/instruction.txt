Инструкция для агента управления Ableton Live — локальный бридж + Remote Script

Версия: 1.1 (Live 11.x)

Каналы связи
- HTTP бридж: POST /cmd, GET /state, WS /events (локально: http://127.0.0.1:8787)
- Remote Script: MyAgent (Ableton API ableton.v2)

Скоуп и безопасность
- Работать с помеченными сущностями [AGENT], либо по точному имени трека/устройства по запросу пользователя.
- Dry‑run/подтверждения — по решению оператора (по умолчанию выполнение сразу, с логами).
- Guard‑rails: не трогать мастер‑гейн, темп в разумных пределах.

Новые возможности v1.1
1) create_midi_track: создание MIDI‑дорожки с именем/индексом, опционально arm.
2) Транспорт/клипы: play, stop, set_tempo, create_midi_clip, set_clip_notes, add_notes, launch_clip.
3) Состояние: request_state (для /state).
4) Параметры устройств: set_param, toggle_device, set_macro — управление параметрами уже существующих устройств на дорожке.

Важно: загрузка устройств из Browser
- API Live 11 (LOM) не предоставляет официального способа программно «загрузить» новый девайс из Browser на дорожку. Поэтому добавление инструмента выполняется вручную пользователем, либо используется заранее подготовленный Rack на дорожке. После этого агент может управлять его параметрами (set_param, set_macro, toggle_device).

Формат команд /cmd
{
  "id": "uuid",
  "action": "<имя>",
  "args": { ... }
}

Примеры
- Создать MIDI‑трек 3‑м по счёту, назвать «3 Bass», включить arm:
  {"id":"t1","action":"create_midi_track","args":{"name":"3 Bass","index":2,"arm":true}}
- Создать клип:
  {"id":"c1","action":"create_midi_clip","args":{"track":"3 Bass","slot":0,"bars":2,"loop":true}}
- Задать ноты:
  {"id":"n1","action":"set_clip_notes","args":{"track":"3 Bass","slot":0,"notes":[{"p":40,"s":0.0,"d":1.0,"v":100}]}}
- Включить устройство на дорожке и изменить параметр:
  {"id":"p1","action":"toggle_device","args":{"track":"3 Bass","device":"Operator","on":true}}
  {"id":"p2","action":"set_param","args":{"track":"3 Bass","device":"Operator","param":"Filter Freq","value":200.0}}
- Установить макро (для Instrument Rack):
  {"id":"m1","action":"set_macro","args":{"track":"3 Bass","device":"Bass Rack","macro":1,"value":0.35}}

Состояние (/state)
- Возвращает tempo, is_playing, tracks[] (name, is_armed)


Database Setup (PostgreSQL)
--------------------------
The project uses a PostgreSQL 16 database with the pgvector extension, managed by Docker.

- Configuration: See docker-compose.yml
- Initialization: See init.sql for the database schema.
- To Start: Run `docker compose up -d` from the project root.
- DB Name: music_kb
- User: kb_user
- Password: See docker-compose.yml (change the placeholder!)

Schema includes tables for: videos, video_segments, recipes, reference_profiles, midi_patterns, arrangement_plans, action_sequences, devices, and embeddings.
