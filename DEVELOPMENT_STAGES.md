## 🔷 ЭТАП 2: БАЗОВАЯ ИНТЕГРАЦИЯ С ABLETON

### Цель этапа:

Создать рабочую связь между MCP сервером и Ableton Live через AbletonOSC.

### 2.1 OSC клиент для AbletonOSC

- Создать базовый OSC клиент (python-osc)
- Реализовать отправку простых команд
- Реализовать получение ответов (если нужно)
- Добавить обработку ошибок подключения
- Реализовать reconnect логику

### 2.2 Базовые операции с Ableton

- **Transport контроль**: play, stop, record, tempo
- **Track management**: создание треков (MIDI/Audio/Return)
- **Clip operations**: создание клипов, добавление нот
- **Device control**: загрузка устройств, управление параметрами
- **Mixer control**: volume, pan, sends

### 2.3 Минимальный MCP сервер

- Создать базовый MCP Server
- Зарегистрировать первые 3-5 tools
- Реализовать list_tools()
- Реализовать call_tool()
- Добавить базовую обработку ошибок

### 2.4 Первые тесты

- Unit тесты для OSC клиента (с моками)
- Integration тесты (требуют запущенный Ableton)
- Тесты для MCP tools
- Coverage отчет

### ✅ Критерий завершения этапа:

- MCP сервер можно запустить и подключить к Claude Desktop
- Можно установить темп в Ableton через промпт Claude
- Можно создать трек и добавить MIDI ноты
- Тесты покрывают >60% кода

- Автоматизация параметров

### 3.4 Интеграция с MCP

- Создать MCP tools для генерации
- Добавить параметры: key, scale, tempo, bars, style
- Реализовать валидацию входных данных
- Добавить примеры промптов в документацию

### ✅ Критерий завершения этапа:

- Тесты покрывают >70% кода

## 🔷 ЭТАП 4: СТИЛИ И ЖАНРЫ

### Цель этапа:

Добавить специфичную логику для разных музыкальных стилей (особенно Goa Trance).

### 4.1 Базовый класс Style Plugin

- Создать абстрактный класс StylePlugin
- Определить интерфейс для стилей
- Создать StyleRegistry для регистрации стилей
- Реализовать механизм выбора стиля

### 4.2 Goa Trance Style (приоритет)

- **Tempo**: 138-145 BPM
- **Scales**: Harmonic minor, Phrygian dominant
- **Lead**: Быстрые психоделические арпеджио
- **Bass**: Rolling 16th notes
- **Drums**: 4-on-the-floor kick, busy hi-hats
- **Structure**: Длинные билды, атмосферные брейки
- **FX**: Reverb, delay, фильтр sweep автоматизация

### 4.3 Дополнительные стили (опционально)

- **Psytrance**: 140-150 BPM, более агрессивный
- **Techno**: 120-135 BPM, минималистичный
- **Ambient**: 60-90 BPM, атмосферный

### 4.4 Параметры стилей

- Preset для синтезаторов под каждый стиль
- Типичные аккордовые прогрессии
- Характерные ритмические паттерны
- Звуковой дизайн (фильтры, резонанс и т.д.)

### ✅ Критерий завершения этапа:

- Можно написать "создай goa trance трек" и получить характерный результат
- Стиль влияет на все аспекты: темп, гаммы, мелодии, ритмы
- Легко добавить новый стиль (1 файл)
- Документация описывает каждый стиль
